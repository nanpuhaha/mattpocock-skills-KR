# 기타 스킬 (Misc)

보관 중이나 자주 사용되지 않으며 공식 플러그인에서 홍보되지 않는 도구들입니다.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: 위험한 Git 명령어(push, reset --hard, clean 등) 실행을 사전에 차단하는 Claude Code 훅 설정.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**: 테스트 파일의 `as` 타입 단언을 `@total-typescript/shoehorn`으로 마이그레이션.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**: 문제, 솔루션, 설명이 포함된 실습 예제 디렉토리 구조 스캐폴딩.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: Husky, lint-staged, Prettier, 타입 체크 및 테스트를 위한 pre-commit 훅 설정.
