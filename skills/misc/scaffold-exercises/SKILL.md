# 실습 예제 스캐폴딩 (Scaffold Exercises)

`pnpm ai-hero-cli internal lint`를 통과하는 실습 예제 디렉토리 구조를 스캐폴딩합니다.

## 디렉토리 명명 규칙

- **섹션**: `exercises/XX-section-name/`
- **예제**: `exercises/XX-section-name/XX.YY-exercise-name/`

## 예제 구성 요소

- `problem/`: 문제 및 TODO
- `solution/`: 정답 구현체
- `explainer/`: 개념 설명
