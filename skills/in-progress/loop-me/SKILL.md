워크플로우 스펙 작성을 목표로 하는 상태 유지형 `/grilling` 세션을 실행합니다.

- **루프(Loop)**: 일상, 업무 등에서 반복되는 패턴.
- **워크플로우(Workflow)**: 루프를 현실화한 스펙 문서 (`workflows/*.md`).
- **트리거(Trigger)**: 이벤트 또는 스케줄.
- **체크포인트(Checkpoint)**: 사람의 검증이나 결정이 필요한 지점.
- **오른쪽으로 밀기(Push right)**: 사람 개입 지점을 가능한 한 뒤로 미루고 앞단의 작업을 자동화.

구현자 에이전트가 단 하나의 추가 질문 없이도 바로 코드를 작성할 수 있을 만큼 완벽히 명세될 때까지 심문하세요.
