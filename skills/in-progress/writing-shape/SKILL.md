원자재(Fragments 등) 마크다운 파일을 입력받아 문단별로 논의하며 독립된 완성 기사로 조립합니다.

1. **원자재 읽기**: 입력 파일을 읽고 전체 내용을 파악합니다.
2. **사전 지식(Grounding) 설정**: 독자의 사전 배경 지식을 확정합니다.
3. **도입부 후보 2~3개 초안 작성**: 논점과 각도가 다른 도입부를 제시하고 사용자가 선택합니다.
4. **문단별 구체화 (Grow paragraph by paragraph)**: "이 도입부에 이어 독자가 다음에 알아야 할 내용은 무엇인가?"를 논의하며 원자재에서 적절한 내용을 추출하고 최적의 형식(줄글, 리스트, 표, 콜아웃, 코드 블록)을 결정합니다.
5. **실시간 반영**: 합의된 문단을 기사 파일에 순차적으로 작성합니다.
6. 글이 완성될 때까지 반복합니다.
