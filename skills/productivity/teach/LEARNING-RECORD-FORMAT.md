# 학습 기록(Learning Record) 형식

학습 기록은 `./learning-records/`에 순차적 번호(`0001-slug.md`, `0002-slug.md` 등)로 저장됩니다. 첫 번째 기록이 필요할 때 디렉토리를 생성합니다.

소프트웨어 개발의 ADR과 유사하게, 향후 세션을 이끌어갈 핵심 인사이트, 사전 지식, 수정된 오개념을 기록하여 근접 발달 영역(ZPD)을 계산하는 데 활용됩니다.

## 템플릿

```md
# {배우거나 확립된 내용의 간결한 제목}

{1~3문장: 무엇을 배웠으며(또는 어떤 사전 지식이 확인되었으며), 이것이 향후 세션에 왜 중요한가.}
```

## 작성 시점

- 사용자가 사소하지 않은 개념에 대해 진정한 이해를 입증했을 때
- 사용자가 이미 알고 있는 사전 지식을 공개했을 때
- 잘못된 오개념이 교정되었을 때
- 학습 결과에 따라 미션이 전환되었을 때

(단순히 다룬 진도나 활동 일지는 작성하지 마세요.)
